# วาดเล่น สมุดวาดเส้นขยับได้

เว็บวาดรูปที่เส้นขยับได้เอง เปิดได้ทั้งบนคอม แท็บเล็ต และมือถือ วาดคนเดียวก็ได้ หรือเปิดห้องวาดกับเพื่อนก็ได้

## มีอะไรบ้าง

- **ดินสอยุกยิก** เส้นดินสอที่สั่นไปมาเหมือนการ์ตูนวาดมือ
- **เส้นพิกเซล** เส้นแบบเกม 8-bit ที่ขยับเป็นขั้น ๆ
- **เส้นหยัก** เลือกได้ 3 ลาย คือ ฟันเลื่อย คลื่น และขดสปริง หยักจะวิ่งไปตามเส้น
- **สีน้ำมัน** แปรงเนื้อพู่กัน ขอบขุย สีโปร่งทาทับกันแล้วไล่สีเข้ากัน ปรับความเข้มสีได้
- **ปากกาขอบ** เส้นสีมีขอบรอบแบบสติกเกอร์ เลือกสีขอบได้ (ดำ ขาว หรือเข้มกว่าสีเส้น) และปรับความหนาขอบได้ ปลายเส้นเลือกได้ 2 แบบ คือแหลม (หนาบางตามแรงกดหรือความเร็ว) หรือมน (หนาเท่ากันตลอดเส้น)
- **ความทึบ** ดินสอ เส้นพิกเซล และเส้นหยัก ปรับให้โปร่งได้ วาดทับกันหลายรอบแล้วสีจะเข้มขึ้นเรื่อย ๆ
- **ยางลบ** ลบเฉพาะเส้น กระดาษไม่หาย
- **กระดาษ 8 แบบ** ขาว สมุด ตาราง จุด คราฟท์ กระดาษเก่า กระดานดำ พิมพ์เขียว
- **หน้ารวมห้อง** เห็นทุกห้อง ทั้งห้องสาธารณะและห้องส่วนตัว เจ้าของลบห้องของตัวเองได้ และทุกห้องหายเองเมื่อครบ 3 วัน
- **วาดกับเพื่อน** เห็นเส้นของกันและกันแบบสด ๆ ห้องละ 2 คน
- **วาดคนเดียว** ไม่ต้องสร้างห้อง ไม่ใช้ Firebase เลย รูปเก็บในเบราว์เซอร์ของคนนั้นเอง
- ซูมเข้าออกและเลื่อนกระดาษได้ ลายกระดาษซูมตามเส้น ขนาดแปรงวัดบนกระดาษ ซูมเท่าไหร่ก็ได้เส้นหนาเท่ากัน
- **ตัวเลือกสี** วงล้อสี แถบความสว่างสลับได้ 2 แบบ (ปกติ / ตามสายตา) รหัสสี HEX พร้อมปุ่มคัดลอก สีที่เพิ่งใช้ 8 สี และเก็บสีไว้ใช้ได้ 24 สี
- **หลอดดูดสี** แตะที่ภาพเพื่อเอาสีตรงนั้นมาใช้ต่อ
- **ดูภาพขาวดำ** สลับดูทั้งภาพเป็นขาวดำชั่วคราว ไว้เช็กแสงเงา (ไม่เปลี่ยนสีจริง ไม่ติดไปตอนบันทึกรูป)
- **ปรับสีทั้งเลเยอร์** เลื่อนโทนสีหรือความสว่างของทุกเส้นในเลเยอร์ทีเดียว ย้อนกลับได้
- **เลเยอร์** (ตอนวาดคนเดียว) เพิ่ม ลบ เปลี่ยนชื่อ เลื่อนขึ้นลง ซ่อน ปรับความโปร่ง และรวมลงเลเยอร์ข้างล่างได้ ยางลบลบเฉพาะเลเยอร์ที่เลือก
- Undo Redo ล้างกระดาษ หยุดหรือเล่นเส้น
- **บันทึกรูป** เป็นภาพนิ่ง (PNG) หรือภาพขยับ (GIF) ที่เส้นขยับยุกยิกเหมือนบนจอ วนเล่นไม่รู้จบ
- **แกลเลอรี่** แชร์รูปพร้อมชื่อรูป ชื่อคนวาด และช่องทางติดต่อ (ได้ 2 คน) เลือกได้ว่าจะขึ้นแกลเลอรี่ หรือให้เห็นเฉพาะคนมีลิงก์ คนดูกดหัวใจ รายงานรูปไม่เหมาะสม และกด **วาดต่อ** เพื่อเอารูปไปเป็นเลเยอร์ใหม่บนกระดาษตัวเองได้ รูปเก็บเป็นเส้น เปิดดูแล้วเส้นยังขยับอยู่

## ไฟล์ในโปรเจกต์

```
index.html              หน้าแรก รวมห้องทั้งหมด สร้างห้อง และปุ่มวาดคนเดียว
draw.html               กระดานวาด (ใช้ทั้งวาดคนเดียวและวาดในห้อง)
gallery.html            แกลเลอรี่รูปที่แชร์
art.html                หน้าดูรูปทีละรูป (art.html?id=รหัสรูป)
firebase-config.js      ค่าตั้งค่า Firebase สำหรับโหมดวาดกับเพื่อน
database.rules.json     กฎความปลอดภัยของฐานข้อมูล (นำไปวางใน Firebase)
styles/                 หน้าตาเว็บ (CSS)
  shared.css            ส่วนที่ใช้ทั้งสองหน้า
  lobby.css             หน้าแรก
  draw.css              กระดานวาด
src/                    โค้ดทั้งหมด (TypeScript)
  shared/firebase.ts    ต่อ Firebase รหัสห้อง และรหัสผ่านที่จำไว้ (ใช้ทั้งสองหน้า)
  i18n/                 สลับภาษาไทย / อังกฤษ (en.ts คือคำแปล)
  lobby/                หน้าแรก
    main.ts             ปุ่มต่าง ๆ และเริ่มต้นหน้า
    rooms.ts            รายการห้อง สร้างห้อง ลบห้อง
    art.ts              ภาพขยับในแบนเนอร์
  draw/                 กระดานวาด
    main.ts             เริ่มต้นกระดาน
    types.ts            ชนิดข้อมูลหลัก (เส้น เลเยอร์ ค่าตั้งค่า)
    core.ts             ค่าที่ใช้ร่วมกันทั้งกระดาน
    util.ts             เครื่องมือเล็ก ๆ (สุ่ม เกลี่ยเส้น ตรวจค่า)
    geometry.ts         รูปเส้นของแต่ละแปรง และปากกาขอบ
    paint.ts            แปรงสีน้ำมัน
    render.ts           วาดลงจอทุกเฟรม
    layers.ts           เลเยอร์
    paper.ts            ลายกระดาษ
    view.ts             ซูมและเลื่อนกระดาษ
    input.ts            รับการวาดจากเมาส์ นิ้ว และปากกา
    history.ts          Undo Redo
    ui.ts               ปุ่มและแผงเครื่องมือ
    color.ts            แปลงสี (HSV และแบบตามสายตา)
    picker.ts           ตัวเลือกสี
    adjust.ts           ปรับสีทั้งเลเยอร์
    saveImage.ts        บันทึกรูป PNG และ GIF
    gif.ts              ตัวเข้ารหัสไฟล์ GIF
    room.ts             ห้องวาดกับเพื่อน
    keyboard.ts         ปุ่มลัด
    persist.ts          จำรูปไว้ในเบราว์เซอร์
package.json            บอกว่าต้องใช้ TypeScript รุ่นไหน
tsconfig.json           ตั้งค่า TypeScript (เปิดการตรวจแบบเข้มงวด)
.github/workflows/      สั่ง GitHub ให้แปลงโค้ดและขึ้นเว็บให้เอง
```

เบราว์เซอร์อ่าน TypeScript ตรง ๆ ไม่ได้ ต้องแปลงเป็น JavaScript ก่อน (ได้โฟลเดอร์ `dist/`) ขั้นนี้ GitHub ทำให้เองทุกครั้งที่อัปโค้ด ไม่ต้องอัปโฟลเดอร์ `dist/` ขึ้นไป

ถ้ายังไม่ตั้งค่า Firebase เว็บก็ใช้วาดคนเดียวได้ตามปกติ แค่ส่วนห้องจะยังใช้ไม่ได้

## สองภาษา (ไทย / อังกฤษ)

- กดปุ่ม TH / EN ที่มุมขวาบนของหน้าแรก หรือในแผงเครื่องมือของกระดานวาด เว็บจะจำภาษาที่เลือกไว้
- เปิดครั้งแรก เว็บเลือกภาษาให้ตามภาษาของเบราว์เซอร์
- หน้าเว็บเขียนเป็นภาษาไทยตามปกติ โค้ดใน `src/i18n/` จะเปลี่ยนเป็นภาษาอังกฤษให้เอง
- อยากแก้คำแปล ให้แก้ในไฟล์ `src/i18n/en.ts` (ฝั่งซ้ายคือคำไทยบนหน้าเว็บ ฝั่งขวาคือคำอังกฤษ)
- ถ้าเพิ่มข้อความไทยใหม่ในหน้าเว็บ อย่าลืมเพิ่มคำแปลใน `src/i18n/en.ts` ด้วย ถ้าไม่ใส่ ข้อความนั้นจะยังเป็นภาษาไทยตอนเลือก EN
- ชื่อห้องที่คนตั้งเองจะไม่ถูกแปล

## ขึ้นเว็บด้วย GitHub Pages

1. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดขึ้น repository (ยกเว้น `dist/` และ `node_modules/` ถ้ามี)
   โฟลเดอร์ `.github` ขึ้นต้นด้วยจุด บางเครื่องจะซ่อนไว้ ต้องอัปขึ้นไปด้วย ไม่งั้นเว็บจะไม่ขึ้น
2. ไปที่ **Settings** แล้วเลือก **Pages**
3. ตรง **Source** เลือก **GitHub Actions** (ทำครั้งเดียว)
4. ไปที่แท็บ **Actions** จะเห็นงาน "ขึ้นเว็บ GitHub Pages" กำลังทำงาน รอจนขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 1 นาที)
5. เปิดลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/` ได้เลย

ต่อจากนี้แก้หรืออัปไฟล์เมื่อไหร่ GitHub จะตรวจโค้ด แปลงเป็น JavaScript แล้วขึ้นเว็บให้เองทุกครั้ง
ถ้าโค้ดมีจุดผิด งานในแท็บ Actions จะขึ้นกากบาทสีแดง และเว็บจะยังเป็นเวอร์ชันเดิม ไม่พัง กดเข้าไปดูได้ว่าผิดที่ไฟล์ไหน บรรทัดไหน

## หรือขึ้นเว็บด้วย Vercel (ผูกกับ GitHub)

1. เข้า [vercel.com](https://vercel.com) แล้วสมัครด้วยบัญชี GitHub
2. กด **Add New > Project** แล้วเลือก repository นี้ กด **Import**
3. Framework Preset เลือก **Other** ตั้ง Build Command เป็น `npm run build` และ Output Directory เป็น `.` แล้วกด **Deploy**
4. ได้ลิงก์ประมาณ `ชื่อ-repo.vercel.app` ต่อจากนี้แก้ไฟล์ใน GitHub เมื่อไหร่ เว็บจะอัปเดตเอง

อย่าลืมเพิ่มโดเมน `.vercel.app` ใน Firebase ที่ Authorized domains (ขั้นที่ 6 ด้านล่าง)

## ตั้งค่าโหมดวาดกับเพื่อน (Firebase)

ทำครั้งเดียว ใช้เวลาประมาณ 10 นาที ใช้แพ็กเกจฟรี (Spark) ได้ ไม่ต้องผูกบัตร

**1. สร้างโปรเจกต์**
เข้า [console.firebase.google.com](https://console.firebase.google.com) กด **สร้างโปรเจกต์** (Create project) ตั้งชื่ออะไรก็ได้ ส่วน Google Analytics จะปิดไว้ก็ได้

**2. เปิดการเข้าใช้แบบไม่ระบุตัวตน**
เมนู **Build > Authentication** กด Get started แล้วไปแท็บ **Sign-in method** เลือก **Anonymous** แล้วกดเปิด (Enable)
ผู้เล่นไม่ต้องสมัครหรือล็อกอิน แต่ระบบจะรู้ว่าใครเป็นใคร เพื่อใช้ตรวจสิทธิ์ในห้อง

**3. สร้างฐานข้อมูล**
เมนู **Build > Realtime Database** กด **Create Database**
- ตำแหน่งเลือก **Singapore (asia-southeast1)** จะเร็วที่สุดสำหรับคนในไทย
- เลือก **Start in locked mode**

**4. ใส่กฎความปลอดภัย**
ในหน้า Realtime Database ไปแท็บ **Rules** ลบของเดิมออกทั้งหมด วางเนื้อหาจากไฟล์ `database.rules.json` แล้วกด **Publish**
(ถ้าแก้ไฟล์ rules เวอร์ชันใหม่เมื่อไหร่ ต้องมาวางใหม่ที่นี่ทุกครั้ง)

**5. คัดลอกค่าตั้งค่ามาใส่**
กดรูปเฟือง > **Project settings** เลื่อนลงไปที่ **Your apps** กดไอคอนเว็บ `</>` ตั้งชื่อแอปแล้วกดลงทะเบียน
จะเห็นค่า `firebaseConfig` ให้คัดลอกค่า `apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId` ไปใส่แทน "ใส่ค่าของคุณ" ในไฟล์ `firebase-config.js`
ถ้าไม่มี `databaseURL` ให้คัดลอกลิงก์จากหัวหน้า Realtime Database (หน้าตาประมาณ `https://ชื่อโปรเจกต์-default-rtdb.asia-southeast1.firebasedatabase.app`)

**6. อนุญาตโดเมนของคุณ**
**Authentication > Settings > Authorized domains** กด Add domain แล้วใส่โดเมนที่ใช้เปิดเว็บ เช่น `ชื่อผู้ใช้.github.io` หรือ `ชื่อ-repo.vercel.app` (ไม่ต้องใส่ https://)

**7. อัปโหลด `firebase-config.js` ที่แก้แล้วขึ้น GitHub** เปิดหน้าแรกแล้วลองสร้างห้องได้เลย

## วิธีเล่นกับเพื่อน

1. เปิดหน้าแรก ตั้งชื่อห้อง เลือก **สาธารณะ** หรือ **ส่วนตัว** แล้วกด **สร้างห้อง** จะเข้าไปที่กระดานทันที
2. กดปุ่มรหัสห้องมุมซ้ายบน แล้วกด **คัดลอกลิงก์** ส่งให้เพื่อน
3. หรือให้เพื่อนเปิดหน้าแรก แล้วเลือกห้องจากรายการ
   - ห้องสาธารณะ: กด **เข้าห้อง** ได้เลย
   - ห้องส่วนตัว: คนอื่นเห็นชื่อห้อง แต่ต้องใส่ **รหัสผ่าน** ก่อน (ระบบสุ่มรหัสผ่านให้ตอนสร้างห้อง ลิงก์ที่คัดลอกจากในห้องมีรหัสผ่านติดไปด้วย)
4. ทั้งสองคนจะเห็นกระดาษสี่เหลี่ยมแผ่นเดียวกัน (ย่อขยายให้พอดีจอแต่ละเครื่อง)
5. ปุ่ม Undo จะย้อนเฉพาะสิ่งที่คุณทำเอง ไม่ไปลบเส้นของเพื่อน
6. ออกจากห้องเมื่อไหร่ รูปที่คุณวาดคนเดียวไว้จะกลับมาเหมือนเดิม

**การลบห้อง**
- เจ้าของห้องกด **ลบห้อง** ในหน้าแรกได้ (กดสองครั้งเพื่อยืนยัน) คนที่อยู่ในห้องจะถูกพาออกให้เอง
- ทุกห้องหายเองเมื่อครบ 3 วันหลังสร้าง ห้องจะหายจากรายการทันทีที่ครบเวลา และข้อมูลจะถูกลบจริงเมื่อมีคนเปิดหน้าแรกครั้งถัดไป ไม่ต้องใช้แพ็กเกจเสียเงิน
- "เจ้าของ" คือเบราว์เซอร์ที่สร้างห้อง ถ้าเปิดจากเครื่องอื่นหรือล้างข้อมูลเบราว์เซอร์ จะลบเองไม่ได้ ต้องรอครบ 3 วัน หรือลบใน Firebase console

## แกลเลอรี่

1. วาดเสร็จแล้วกด **บันทึกรูป** แล้วกด **แชร์ไปแกลเลอรี่**
2. ใส่ชื่อรูป ชื่อคนวาด และช่องทางติดต่อ (ไม่ใส่ก็ได้ ถ้าขึ้นต้นด้วย https:// จะกดเป็นลิงก์ได้)
3. เลือก **แสดงในแกลเลอรี่** หรือ **เฉพาะคนมีลิงก์** แล้วกด **แชร์รูป** จะได้ลิงก์ของรูปไว้ส่งต่อ

- รูปอยู่ถาวร เจ้าของลบเองได้ที่หน้ารูป (ปุ่มสามจุด > ลบรูปนี้)
- รูปที่ถูกรายงานตั้งแต่ 3 ครั้งขึ้นไปจะถูกซ่อนจากแกลเลอรี่ (ยังเปิดจากลิงก์ได้) ถ้าจะลบถาวร ลบใน Firebase console แท็บ **Data** ทั้ง `art/รหัส` และ `gallery/รหัส`
- ใช้ Realtime Database ตัวเดิม แพ็กเกจฟรีพอ ไม่ต้องใช้ Cloud Storage เพราะเก็บรูปเป็นข้อมูลเส้น บวกรูปย่อเล็ก ๆ สำหรับหน้าแกลเลอรี่
- "เจ้าของ" คือเบราว์เซอร์ที่แชร์รูป เหมือนเจ้าของห้อง ถ้าล้างข้อมูลเบราว์เซอร์ จะลบเองไม่ได้ ต้องลบใน Firebase console

## เรื่องความปลอดภัย

**ทำไว้ให้แล้ว**
- ค่าใน `firebase-config.js` เปิดให้คนอื่นเห็นได้ตามปกติ ตัวที่กันคนแปลกหน้าคือ Security Rules
- อ่านและวาดในห้องได้เฉพาะ 2 คนที่อยู่ในห้องเท่านั้น คนที่ 3 จะเข้าไม่ได้
- รหัสห้องและรหัสผ่านห้องส่วนตัวสุ่มจากตัวอักษร 31 แบบ จำนวน 6 ตัว (ประมาณ 887 ล้านแบบ) เดาสุ่มให้ตรงได้ยาก
- รหัสผ่านห้องส่วนตัวไม่มีใครอ่านจากฐานข้อมูลได้ กฎจะเช็กให้เองว่ารหัสที่ใส่ตรงหรือไม่
- ลบห้องได้เฉพาะเจ้าของ หรือเมื่อห้องครบ 3 วันแล้วเท่านั้น และห้องที่ครบ 3 วันจะวาดต่อไม่ได้
- ฐานข้อมูลรับเฉพาะข้อมูลเส้นที่หน้าตาถูกต้อง จำกัดขนาดเส้น จำนวนจุด และค่าต่าง ๆ ไว้
- ฝั่งที่รับก็ตรวจข้อมูลซ้ำอีกรอบ และไม่เอาข้อความที่ได้รับไปแสดงเป็นโค้ด กันการฝังโค้ดอันตราย
- เมื่อหลุดจากห้องหรือปิดเว็บ ที่นั่งในห้องจะว่างให้คนอื่นเข้าได้เอง

**ที่ควรทำเพิ่มเอง**
- **อยู่แพ็กเกจฟรี (Spark) ต่อไป** ถ้าใช้เกินโควตาฟรี ระบบจะหยุดเอง ไม่มีค่าใช้จ่ายโผล่มา ถ้าวันหนึ่งเปลี่ยนเป็นแพ็กเกจจ่ายตามใช้ (Blaze) ให้ตั้งแจ้งเตือนงบประมาณก่อน
- **ชื่อห้องเป็นสิ่งที่ผู้ใช้พิมพ์เอง** ทุกคนในหน้าแรกจะเห็น ถ้าเจอชื่อไม่เหมาะสม ลบได้ในแท็บ **Data** ของ Realtime Database (ลบทั้ง `rooms/รหัส`, `lobby/รหัส` และ `secrets/รหัส`)
- **จำกัด API key ให้ใช้ได้เฉพาะเว็บของคุณ (ไม่บังคับ)** ใน Google Cloud console ไปที่ APIs & Services > Credentials เลือก API key แล้วตั้ง Website restrictions เป็น `https://ชื่อผู้ใช้.github.io/*`
- **ถ้าเปิดให้คนทั่วไปใช้เยอะ ๆ** ลองเปิด Firebase App Check เพิ่ม เพื่อกันสคริปต์อัตโนมัติ

**ข้อจำกัด**
- กฎของฐานข้อมูลจำกัดความถี่ในการส่งข้อมูลไม่ได้ ห้องจึงเหมาะกับวาดกับคนที่รู้จัก ไม่ใช่ห้องสาธารณะ

## แก้โค้ดในเครื่องตัวเอง (ไม่บังคับ)

ถ้าอยากลองแก้และเปิดดูในเครื่องก่อนอัปขึ้น GitHub

1. ติดตั้ง [Node.js](https://nodejs.org) (รุ่น 20 ขึ้นไป)
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์ `npm install` (ทำครั้งแรกครั้งเดียว)
3. พิมพ์ `npm run dev` ทิ้งไว้ ทุกครั้งที่บันทึกไฟล์ใน `src/` จะแปลงเป็น JavaScript ให้เอง และบอกทันทีถ้าโค้ดผิด
4. เปิดอีกหน้าต่าง พิมพ์ `npx serve .` แล้วเปิดลิงก์ที่ขึ้นมาในเบราว์เซอร์
   (เปิดไฟล์ html ด้วยการดับเบิลคลิกตรง ๆ ไม่ได้ เพราะเบราว์เซอร์ไม่ยอมโหลดโค้ดแบบแยกไฟล์จากเครื่อง)

คำสั่งอื่น
- `npm run check` ตรวจโค้ดอย่างเดียว ไม่สร้างไฟล์
- `npm run build` แปลงโค้ดครั้งเดียว
